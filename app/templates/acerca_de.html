ℹ️ Acerca del Sistema

Sistema de Riego Automatizado

Sistema desarrollado para optimizar el riego y aplicacion de fertilizante en invernaderos usando drones roboticos

Objetivos del Proyecto

  • Optimizar el uso de agua y fertilizante
  • Automatizar el proceso de riego
  • Generar reportes detallados del proceso
  • Reducir tiempos de ejecucion

🛠️ Tecnologias Utilizadas

Backend: Python, Flask
Frontend: HTML5, CSS3, Jinja2
TDAs: Listas Enlazadas, Pilas, Colas
Reportes: Graphviz

📊 Caracteristicas Principales

✅ Carga de archivos XML
✅ Procesamiento de planes de riego
✅ Generación de instrucciones
✅ Reportes HTML y graficos
✅ Exportacion de resultados
✅ Interfaz web responsive
